## 🚀 Deployment

This portfolio is deployed using **GitHub Pages**. 

### Current Deployment
- **URL**: https://jasonlhc.github.io/li-hsiang-chao-portfolio/
- **Branch**: `main`
- **Automatic deployment**: Enabled - changes to `main` are automatically deployed

### To deploy changes:
1. Make your changes locally
2. Commit your changes: `git commit -m "Your message"`
3. Push to GitHub: `git push origin main`
4. GitHub Pages will automatically rebuild and deploy your site (may take 1-2 minutes)
